🚨 安全与白名单(动这里前请想清楚)

填聊天窗口显示的名字:备注优先,没有备注则填对方昵称。

两层保险:第一层是发送模式二选一,永远不会出现「又演练又真实」的状态;第二层是白名单 + 发送前自动核对聊天窗口名字。只要保持演练模式,就绝不会发出任何消息。

👥 群聊(默认全关)

⚠️ 群聊默认不会真发消息:即使选了「有人 @机器人 时才回复」或「所有人都回」,也只会把"想回什么"记进日志。要让群聊真发,得同时满足:已启用群聊、群在群白名单里、再手动到 config.json 打开群聊真实发送开关(本页不提供这个开关,慎开)。另外,群消息识别按微信 4.x 常见界面实现,还没在真实群聊里充分验证,第一次使用请盯着日志确认识别是否正常。

🔑 访问口令(远程访问与本机登录)

这个口令用来登录本页面:在自己电脑上打开要输,从外网远程访问也要输。修改后立即生效,其他已登录的浏览器会被要求重新登录。

🧠 智能体后端(决定消息由谁来回,可配多个)

每个后端就是一个「回复来源」,四类任选:echo(回声测试,不用填配置)/ openai(接 GLM、DeepSeek 等 AI)/ webhook(接你自己常驻在线的服务)/ mailbox(信箱,接 Muse)。

删除后端前,先确认下方路由表没有联系人指向它(否则保存会被拒绝)。

🧭 按联系人路由(谁的消息交给谁回)

联系人填聊天窗口显示的名字:备注优先,无备注填昵称(与白名单同规则)。 路由表里没有的联系人一律走「默认后端」;指向不存在后端的路由会被拒绝保存。

还没有路由规则:目前所有联系人都走默认后端。

🚀 三步上手
  1. 安装依赖(只需一次):命令行里执行 pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
  2. 登录电脑版微信,然后在项目文件夹执行 python run.py
  3. 浏览器会自动打开本页面。先看「① 状态」:三个卡片都绿了再谈下一步。
✅ 首次自检清单
  1. 「微信窗口」显示已找到 —— 没找到就登录微信、别最小化到托盘;
  2. 保持默认 echo 模式 + 演练模式,点「启动引擎」,看「② 实时日志」滚动是否正常;
  3. 用手机给白名单联系人(默认为「文件传输助手」)发条消息,日志里应能看到引擎发现并"演练回复"(不真发);
  4. 一切正常后,想真发消息再去「④ 配置」把「发送模式」切成「允许真实发送」 (切换和保存时都会再跟你确认一次,而且只能发给白名单里的人)。
❓ 常见问题
微信窗口显示"未找到"?
请登录电脑版微信 4.x 并让主界面处于打开状态。最小化到托盘也没关系,引擎启动后会自动恢复窗口。
微信最小化了会影响吗?
不影响。引擎需要时会自动恢复窗口并置前(可能闪一下);不需要时你随意最小化。
日志里出现"空白壳/渲染未恢复"?
微信偶发"窗口在但一片空白",程序会自动按 Ctrl+Alt+W 反复尝试让微信自己重画,一般几秒内自愈,无需处理。
启动报错 MSVCP140.dll / onnxruntime?
先装微软 VC++ 2015-2022 运行库(x64):https://aka.ms/vs/17/release/vc_redist.x64.exe
OCR 第一次特别慢?
正常。OCR 模型首次加载要几秒到几十秒,之后会变快。
提示端口被占用?
用别的端口启动:python run.py --port 8888,然后手动访问 http://127.0.0.1:8888
浏览器没有自动打开?
手动在浏览器输入 http://127.0.0.1:8765(端口以命令行窗口显示为准)。
想给不同联系人用不同的 AI(或接入 Muse 信箱)?
「④ 配置 → 🧠 智能体后端」可添加多个后端(echo / openai / webhook / mailbox 四类), 「🧭 按联系人路由」指定某个联系人固定用哪个后端回复,路由表没有的联系人走「默认后端」; 接入 Muse 信箱用 mailbox 类型后端卡片(监听范围自动跟随白名单,无需单独配置; 卡片内有「接入指引」与归档保留时长,协议详见 docs/PROTOCOL.md)。
🔒 安全须知(务必阅读)
  • 白名单机制:机器人只跟白名单里的联系人(默认仅「文件传输助手」)收发消息,其他联系人的消息一律忽略;白名单可填多个联系人(每行一个);
  • 群聊默认全关:引擎默认不打开、不读取、不回复任何群聊;群聊的回复默认也只记日志不真发,要真发还需再满足几个条件(见「④ 配置 → 👥 群聊」),最后一个开关本页不提供;
  • 发送模式二选一:默认「演练模式」只把"将要发送什么"记进日志,不动鼠标键盘;切成「允许真实发送」才会真的发(程序内部保证开关永远一致,不会半真半假)。
  • 急停:鼠标快速甩到屏幕左上角,立即停下一切自动操作(详见「① 状态」页的紧急停止说明);
  • 访问口令:打开本页要先输口令,外网远程访问也一样;口令在程序第一次启动时自动生成(启动窗口会打印一次),可在「④ 配置」页修改;
  • 本页面默认只有你这台电脑能打开,同一网络里的其他人访问不到;要从外网访问只能走 Cloudflare 隧道(需口令),请不要用别的方式把它暴露到网上;
  • 请遵守微信使用规范,不要用来骚扰他人或群发广告。

🔒 请输入访问口令

本控制台已开启口令保护。口令在服务首次启动时自动生成 (启动窗口会醒目打印一次,也写进了 config.json 的 web.password 字段), 可在「④ 配置」页修改。通过公网隧道远程访问时同样使用这个口令。
